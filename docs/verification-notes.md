# یادداشت‌های اعتبارسنجی

## 2026-08-25 — بررسی محلی تولید

ساخت تولیدی با موفقیت انجام شد و سرور محلی روی `http://localhost:3000/` پاسخ‌گو است. بازبینی دستی مسیر `/reports` نشان داد که در محیط جداشدهٔ توسعه، لایهٔ احراز هویت پیش از محتوای داشبورد فعال می‌شود و به دلیل نبود پیکربندی OAuth محلی، صفحهٔ ورود نمایش داده می‌شود. این رفتار از عبور غیرمجاز از کنترل دسترسی جلوگیری می‌کند؛ بنابراین برای بازبینی تصویری کاملِ صفحات محافظت‌شده باید یک نشست کاربری مجاز یا پیکربندی OAuth محیط انتشار فراهم شود.

اعتبارسنجی‌های مستقل از OAuth که اجرا شده‌اند: `npm run check` با موفقیت، `npm run build` با موفقیت، و `npm test` با موفقیت. قابلیت‌های جدید صدور خروجی فقط با اقدام صریح کاربر فعال می‌شوند و در نسخهٔ دسکتاپ، ذخیره‌سازی را از مسیر انتخاب فایل بومی ویندوز انجام می‌دهند.
